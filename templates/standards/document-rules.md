# Outline 单篇文档创作规范

## 一、标题设计
- 准确传达主旨，不包含例如“XX文档”、“新建文档”、“需求测试”等冗余词汇。

## 二、标签 (Tags) 运用
- 正规归档发布的业务知识点，必须在文档末尾加上对应业务的小写标签，例如 `#用户端`、`#前端技术栈`。标签需统一管理，避免不同人写错缩写。

## 三、摘要前置机制
- 黄金三句：打开长文本的第一眼，必须在首部提供包含背景与结论的简要摘要。即使被通过 API 拉取也能呈现优美的 Text Preview。

## 四、生命周期与状态标志
- 【编写期】：必须维持 Draft 状态，不提前公布污染搜索流。
- 【维稳期】：保持 Published 状态，文档页头最好标注清晰 `Author`。
- 【下线期】：请及时 Archived。长久不更新、失去参考价值的内容请带上弃用头警告并进入归档区。
