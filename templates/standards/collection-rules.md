# Outline Collection 层级组织规范

## 一、核心原则
- **逻辑清晰**：必须按业务线或职能领域划分，不设“大杂烩”、“个人工作区”此类的含糊 Collection。
- **层级克制**：整体嵌套深度推荐控制在 3 层内，过深会导致左侧导航树不易查找（Collection -> 大分类文档 -> 具体小叶子文档）。

## 二、配置规则
- **包装完整**：每一个 Collection 在创建时，必须为它配置合适的封面图（Cover）和 Icon 图标。
- **默认权限**：若非全员公开信息，新建 Collection 请设为私密，并按组（Group）划分进入权限。

## 三、目录排序
- **自然排序逆向法**：由于 Outline 默认新文档在上，如果有必须按“第一部分、第二部分”排序的文档集，请逆序创建（先建第二部，再建第一部）；或者调用 Skill 的 `collection reorder` 命令按标题名称重新对嵌套节点排序。
